# Project Development Phase

The completed application source code is maintained in the project root `app/` directory.

## Main Development Components
- `app/main.py` - FastAPI application
- `app/config.py` - configuration
- `app/services/gemini.py` - Gemini integration
- `app/services/comic.py` - comic generation logic
- `app/services/pdf_export.py` - PDF export
- `app/templates/` - HTML templates
- `app/static/` - CSS and JavaScript
